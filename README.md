# Sustainable-Waste-Management-System-China
Intelligent multi-stage YOLO-based waste visual classification system for Sustainable Waste Management (SWMS) focused on China area rules &amp; categories. Includes Stage-1 router + Stage-2 specialists (Food, Harmful, Recyclable, Others), edge-ready models (ONNX/TFLite), evaluation dashboards, and IoT/Blockchain research context.
